# Solution Guide

Solutions are grouped by topic, then by language.

## Topics

- Arrays
- Strings
- Linked Lists
- Stacks and Queues
- Trees
- Graphs
- Dynamic Programming
- Other

## Naming convention

Use the LeetCode problem number followed by a kebab-case title:

- `0001-two-sum.py`
- `0001-two-sum.java`

## Recommended header

Each solution should record:

- LeetCode problem URL
- Short explanation of the approach
- Time complexity
- Space complexity

Language folders will be created automatically when the first corresponding solution is added.
